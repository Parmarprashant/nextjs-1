# Everyday Recipes

Everyday Recipes is a simple recipe website built with Next.js and TypeScript. Users can explore recipes, search for recipes, view recipe details, browse cuisines, and add their own recipes.

## Features

- View recipes
- Search recipes by name and cuisine
- View recipe details
- Browse cuisines
- Add new recipes
- Save recipes using localStorage
- About page

## Technologies Used

- Next.js
- React
- TypeScript
- Inline CSS
- Browser localStorage

## Getting Started

### 1. Install Dependencies

```bash
npm install
```

### 2. Run the Development Server

```bash
npm run dev
```

### 3. Open the Website

Visit [http://localhost:3000](http://localhost:3000) in your browser.
